そのまま実行できる。

```bash
python examples/01_quickstart.py
```

## 01_quickstart.py — まず全体像

シミュレータで観測を作り、**同じ観測列を Lv0〜Lv3 に通して**比べる。
アルゴリズムの差だけが見えるようになっている。

理論下限 (CRLB) も一緒に出るので、「これ以上良くはならない」線が分かる。
Lv3 は時間方向の情報も使うので、1 エポックの下限を下回ることがある。

**ここを読むと分かること**
- `SimulatedHal` → `Pipeline` → `Fix` という基本の流れ
- RMSE / CEP50 / CEP95 の読み方
- レベルを変えるのは文字列 1 つだけ

## 02_custom_hal.py — 自分のチップにつなぐ

`UwbHal` を継承して、独自プロトコルの HAL を書く。実装するのは
**`anchors` と `poll` の 2 つだけ**。

「1 本ずつバラバラに届く測距を、どうエポックにまとめるか」まで含めて
書いてあるので、実機のファームが 1 行 1 測距で吐くタイプでも参考になる。

**ここを読むと分かること**
- HAL に求められる最小の契約
- `MeasurementBatch` の組み立て方
- 時刻・品質値を載せると何が変わるか

## 03_minimal_integration.py — いちばん短い書き方 3 通り

すでに自分でパースしているなら HAL は要らない、という話。

1. **HAL なし** — 3 行。`make_estimator` に直接投げる
2. **JSON Lines** — ファームに `printf` 1 つ足すだけ
3. **`UwbHal` 継承** — ストリームを自分で握りたいとき

**ここを読むと分かること**
- どの方法でも測位側のコードは変わらない
- 時刻が出せないなら Lv2 を使えばよい

## 04_anchor_layout.py — 置き方が精度を決める

**測位器も測距誤差も固定したまま、配置だけ変えて**測る。

実際に走らせると分かるのは:

- **GDOP は置く前にひどい配置を弾ける** (良い配置 2.3 に対し、悪い配置は 17.25)
- **4 台ではどう置いても苦しい。** 配置を工夫するより台数を足す方が効く
- **同一平面の害は平均誤差に出ない。** 鏡像解という別種の壊れ方をする

鏡像解のところでは、真値と鏡像から**全アンカーへの距離が小数点以下 4 桁まで
一致する**のを実際に表示する。誤差ではなく原理的に選べない、が腑に落ちる。

最後に、相互測距から座標を復元できること (測距誤差 5 cm → 座標誤差 平均 3.7 cm)
も確かめる。

## 05_choose_level.py — Lv0〜Lv3 の選び方

「とりあえず一番良さそうなの」で Lv3 を選ぶと損をすることがある、という話。

- **NLOS が無ければレベル間の差は小さい。** 手法の差は NLOS があって出る
- **4 台では Lv3 が「速いが時々外す」。** 中央値は Lv2 より良いのに、
  最悪ケースは 2.4 m まで伸びる。だから**平均だけでなく最悪も見る**
- **Lv3 は時刻が要る。** 時刻ゼロのまま流すと 1.6 m まで悪化するが、
  一定レートだと分かっていれば合成して戻せる

seed ごとに出して中央値と最悪を並べているのは、平均に埋もれる破綻を
見つけるため。**README の「何台買えばいいか」の表はこれと同じ設定。**

## 06_troubleshooting.py — 壊れ方から原因を当てる

現場でハマる状況を**わざと作って**、どの数字を見れば分かるかを確かめる。

| 症状 | 見るところ |
|---|---|
| 位置が出ない | `fix.ok` / `fix.n_total` (3D は最低 4 本) |
| 座標を間違えた | **Lv0 の** `residual_rms` (Lv2 は隠してしまう) |
| 1 台だけ悪い | `fix.excluded` に同じ ID が出続ける |
| 距離が一定量ずれる | アンテナ遅延。既知距離で測って分離できる |
| 単位を取り違えた | `sniff` が距離の範囲で教えてくれる |

いちばん役に立つのは**「Lv2 は座標ミスを隠す」**という点。A2 の座標を 2 m
間違えても Lv2 の位置と残差は正常に見え、Lv0 だと残差が 0.008 → 0.4 m に
跳ねて一発で分かる。**立ち上げは Lv0、運用は Lv2 + excluded 監視**。

アンテナ遅延のところでは、アンカー側とタグ側の遅延が**定数分だけ分離
できない**ことも見える。個別の値はずれるが**合計は正しい**ので、
`delays[id] + delays["__tag__"]` を入れれば誤差 0.756 m → 0.007 m になる。
